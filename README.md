# My Website

Frontend-only landing page template based on the Stasis retro console aesthetic.

## Getting started

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000).

## What's included

- Animated page border with corner stars and technical readouts
- Canvas noise grain overlay
- Dotted line dividers
- Magnetic corner button styling
- Email signup form (frontend only — no backend)
- Empty hero area for your own title and content

## Customize

- **Logo**: Replace `public/stasis-logo-os.svg` or update the `<img>` in `app/page.tsx`
- **Hero content**: Add your text/images inside the empty hero `<div>` in `app/page.tsx`
- **Footer watermark**: Replace `public/stasis-text.svg` and `stasis-text-stroke.svg`
- **Colors & fonts**: Edit `app/globals.css`

## Build

```bash
yarn build
```
